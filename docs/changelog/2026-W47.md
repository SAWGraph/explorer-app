# Changelog, Week 47, 2026 (Nov 16 to Nov 22)

---

1. **Groundwater-Connected: Entities on the Same Aquifer** (2026-11-16)

    **Component**: `engine/` (planner, `templates/fusedQueries.ts`, `shape.ts`, `errors.ts`), `ui/components/Map/`, `ui/components/QueryEditor/`

    **Change**: Issue #121. A new relationship, "Groundwater-connected to", between samples, facilities and wells: the two entities sit on the same aquifer, so they may share groundwater. Each side's own S2 cell must touch the aquifer, the same test on both sides, so swapping the blocks gives the same answer. The link skips regional aquifers (over about 1,000 km², all 13 in Illinois), and the results notice says how many it skipped. A question with the same type on both sides leaves out an entity matched with itself. The map outlines the aquifers that link the two sides, each with a "Links N samples ↔ M wells" line. A new dashboard question asks for wells groundwater-connected to PFOA groundwater contamination in Kennebec County: 92 wells, 22 samples, 6 aquifers, 5.9s on a warm run.

    **Unchanged**: near, downstream and upstream questions send the same SPARQL as before. The editor greys out the new relationship when a block is surface water or aquifers, and greys out those types once it is chosen. The existing aquifer overlay still comes from `aquifers.geojson`.

    **Files touched**: `engine/planner.ts`, `engine/question.ts`, `engine/templates/fusedQueries.ts`, `engine/executor.ts`, `engine/cacheKey.ts` (`WIRE_VERSION` w4), `engine/shape.ts`, `engine/errors.ts`, `engine/entities/*.ts`, `engine/constants/prebuiltQueries.ts`, `ui/components/Map/LinkAquiferLayer.tsx` (new), `ui/components/Map/ResultsMap.tsx`, `ui/components/QueryEditor/RelationshipSelector.tsx`, `ui/components/QueryEditor/EntityTypeSelector.tsx`, `GLOSSARY.md`, `docs/ARCHITECTURE.md`, `docs/SCHEMA.md`

    **Prevention**: `engine/tests/groundwaterConnected.test.ts` checks, for every point-type pair, the step set and labels, that both sides join the aquifer the same way, that every query carries the regional limit, and the self filter. `engine/tests/groundwaterRun.test.ts` runs the question against a fake endpoint. `ui/tests/mapPanes.test.tsx` and `ui/tests/groundwaterEditor.test.tsx` cover the new pane and the editor gating.
